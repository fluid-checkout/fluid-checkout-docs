**Type:** Filter

Filters the EU VAT number submitted at checkout before it is validated.

Return the VAT number that should be validated and stored. Normalization such as stripping spaces belongs on this filter.

## Signature

```php
apply_filters( 'fc_vat_checkout_eu_vat_number', $vat_number, $country );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$vat_number` | `string` | VAT number entered by the customer, without a country prefix. |
| `$country` | `string` | Billing country code for the current checkout. |
