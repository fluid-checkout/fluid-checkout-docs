**Type:** Filter

Filters whether a field is considered a VAT number field.

Determines whether a specific field is considered a VAT number field, allowing you to extend VAT logic to custom fields. The default is true only when `$field_key` is `billing_vat_number`.

## Signature

```php
apply_filters( 'fc_vat_is_vat_number_field', $is_vat_number_field, $field_key );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$is_vat_number_field` | `bool` | Whether the field is a VAT number field. |
| `$field_key` | `string` | Field key being checked. |
