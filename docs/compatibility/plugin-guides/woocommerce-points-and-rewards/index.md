# Compatibility with WooCommerce Points and Rewards

## Filter and action hooks

### Best practices

If you are unsure about how to add the code snippets to your website, check our article:  
[How to safely add code snippets to your WooCommerce website](https://fluidcheckout.com/docs/how-to-add-code-snippets/)

### Filters

- [`fc_pro_points_rewards_script_settings`](/pro/hooks/fc_pro_points_rewards_script_settings/) – Filters the script settings for points and rewards.
- [`fc_pro_integration_woocommerce_points_and_rewards_redeem_message_hook_priority`](/pro/hooks/fc_pro_integration_woocommerce_points_and_rewards_redeem_message_hook_priority/) – Filters the hook priority for the redeem message.
- [`fc_pro_points_rewards_redemption_message`](/pro/hooks/fc_pro_points_rewards_redemption_message/) – Filters the points redemption message text.
- [`fc_pro_points_rewards_apply_button_classes`](/pro/hooks/fc_pro_points_rewards_apply_button_classes/) – Filters the CSS classes for the apply discount button.
- [`fc_pro_points_rewards_apply_button_text`](/pro/hooks/fc_pro_points_rewards_apply_button_text/) – Filters the text for the apply discount button.
- [`fc_pro_points_rewards_section_title`](/pro/hooks/fc_pro_points_rewards_section_title/) – Filters the section title for points and rewards.
- [`fc_pro_points_rewards_display_section_title`](/pro/hooks/fc_pro_points_rewards_display_section_title/) – Filters whether to display the section title.
