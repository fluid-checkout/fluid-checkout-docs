### Actions

- [`fc_pro_woocommerce_attendee_details_after_fields`](/pro/hooks/fc_pro_woocommerce_attendee_details_after_fields/) – This action hook fires after the WooCommerce attendee details fields are rendered.

### Filters

- [`fc_pro_fooevents_attendee_details_position_args`](/pro/hooks/fc_pro_fooevents_attendee_details_position_args/) – Filters the position arguments for the attendee details substep.
