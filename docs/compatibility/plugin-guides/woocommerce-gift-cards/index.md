# Compatibility with WooCommerce Gift Cards

## Filter and action hooks

### Best practices

If you are unsure about how to add the code snippets to your website, check our article:  
[How to safely add code snippets to your WooCommerce website](https://fluidcheckout.com/docs/how-to-add-code-snippets/)

### Filters

- [`fc_pro_integration_woocommerce_gift_card_code_checkout_section_hook_priority`](/pro/hooks/fc_pro_integration_woocommerce_gift_card_code_checkout_section_hook_priority/) – Filters the hook priority for the gift card code section on checkout.
- [`fc_pro_cart_section_hook_priority_gift_card_code`](/pro/hooks/fc_pro_cart_section_hook_priority_gift_card_code/) – Filters the hook priority for the gift card code section on cart.
- [`fc_pro_checkout_gift-card_code_message_text`](/pro/hooks/fc_pro_checkout_gift-card_code_message_text/) – Filters the message text for the gift card code section.
- [`fc_pro_cart_gift_card_code_field_initially_expanded`](/pro/hooks/fc_pro_cart_gift_card_code_field_initially_expanded/) – Filters whether the gift card code field is initially expanded.
- [`fc_pro_cart_gift_card_code_section_title`](/pro/hooks/fc_pro_cart_gift_card_code_section_title/) – Filters the title for the gift card code section.
