# Plugins compatible with Fluid Checkout

Fluid Checkout has explicit compatibility with 150+ plugins and 90+ themes, and most other plugins and themes work out of the box.

Keep the plugins your site already runs. Fluid Checkout works with payment gateways, shipping plugins, checkout field editors, page builders, and many other WooCommerce plugins, so you can improve your checkout without starting over.

The list below is every plugin with explicit compatibility code in Fluid Checkout Lite and Fluid Checkout PRO together. Each plugin is listed once. Free and Pro editions of the same plugin are one entry. A plugin marked **Fluid Checkout PRO** needs Fluid Checkout PRO, because that is where its compatibility code lives.

Where a plugin needs a specific setting, the entry has a short note and a link to the guide.

### Express checkout buttons

With Fluid Checkout PRO, express payment buttons such as Google Pay, Apple Pay, and Amazon Pay show together at the top of the checkout, before the checkout steps. These payment plugins support that feature. They are already counted in Payment gateways, so they are not extra plugins:

- Dintero Checkout for WooCommerce
- Kustom Checkout for WooCommerce (formerly Klarna Checkout for WooCommerce)
- Nets Easy for WooCommerce
- Payment Plugins Braintree for WooCommerce
- Payment Plugins for PayPal WooCommerce
- Payment Plugins for Stripe WooCommerce
- PaysonCheckout for WooCommerce
- Svea Checkout for WooCommerce
- WebToffee PayPal Express Checkout Payment Gateway for WooCommerce
- WooCommerce Amazon Pay
- WooCommerce Stripe Payment Gateway
- WooPayments

For Google Pay and Apple Pay with WooCommerce Stripe Payment Gateway, avoid extra required fields at checkout. [See the express checkout guide](https://fluidcheckout.com/docs/feature-express-checkout/).

WooCommerce PayPal Payments, Mollie Payments for WooCommerce, and Amazon Payment Services only offer express buttons on the block checkout, so those express buttons do not appear with Fluid Checkout. [See the express checkout guide](https://fluidcheckout.com/docs/feature-express-checkout/).

## When your plugin is not listed

If a plugin is not on this list, it can still work. The list is the plugins we have explicit compatibility code for. Most other plugins work out of the box.

Try Fluid Checkout on your site. If you run into an issue, contact us through the [support forum](https://wordpress.org/support/plugin/fluid-checkout/) and we will help you fix it.

Looking for themes? See [Themes compatible with Fluid Checkout](/compatibility/themes/).

Using the WooCommerce Checkout block? See [WooCommerce Checkout and Cart blocks](/compatibility/woocommerce-blocks/).
