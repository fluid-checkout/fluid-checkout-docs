# Compatibility

Fluid Checkout has explicit compatibility with 150+ plugins and 90+ themes, and most other plugins and themes work out of the box.

These guides are for people setting up Fluid Checkout on a WooCommerce site.

- [Plugins compatible with Fluid Checkout](/compatibility/plugins/)
- [Themes compatible with Fluid Checkout](/compatibility/themes/)
- [WooCommerce Checkout and Cart blocks](/compatibility/woocommerce-blocks/)

The plugin and theme lists cover Fluid Checkout Lite and Fluid Checkout PRO together. On the plugins page, **Fluid Checkout PRO** means the compatibility code for that plugin is part of Fluid Checkout PRO.

Individual setup guides for themes and plugins are linked from those lists.
