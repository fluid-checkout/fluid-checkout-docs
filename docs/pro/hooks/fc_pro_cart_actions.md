**Type:** Action

Fires when outputting the cart actions.

## Signature

```php
do_action( 'fc_pro_cart_actions' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.3.0`

## Source

`inc/cart-page.php`

## Examples

```php
add_action( 'fc_pro_cart_actions',
    /**
     * Add continue shopping link to cart actions.
     */
    function() {
        echo '<a href="' . esc_url( wc_get_page_permalink( 'shop' ) ) . '" class="button">';
        echo esc_html__( 'Continue Shopping', 'text-domain' );
        echo '</a>';
    },
    15
);
```
