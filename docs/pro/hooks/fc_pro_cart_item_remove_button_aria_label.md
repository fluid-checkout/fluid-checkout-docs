**Type:** Filter

Filters the label for cart item remove button aria.

## Signature

```php
apply_filters( 'fc_pro_cart_item_remove_button_aria_label', $name, $cart_item, $cart_item_key, $product );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$name` | `string` | The name. |
| `$cart_item` | `array` | Cart item data. |
| `$cart_item_key` | `string` | Cart item key. |
| `$product` | `\WC_Product` | Product object. |

## Since

- `2.0.5`

## Source

`inc/cart-page.php`

## Examples

```php
add_filter( 'fc_pro_cart_item_remove_button_aria_label',
    /**
     * Customize remove button aria-label.
     *
     * @param string $name The name.
     * @param array $cart_item Cart item data.
     * @param string $cart_item_key Cart item key.
     * @param \WC_Product $product Product object.
     * @return string Filtered value.
     */
    function( $name, $cart_item, $cart_item_key, $product ) {
        return sprintf( __( 'Delete %s from cart', 'text-domain' ), $product->get_name() );
    },
    10,
    4
);
```
