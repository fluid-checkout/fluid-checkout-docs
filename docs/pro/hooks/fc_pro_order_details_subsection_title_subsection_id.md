**Type:** Filter

Filters the title of an order details subsection.

The dynamic portion of the hook name, `$subsection_id`, is the order details subsection ID. Possible hook names include:

- `fc_pro_order_details_subsection_title_downloads`
- `fc_pro_order_details_subsection_title_order_notes`

## Signature

```php
apply_filters( 'fc_pro_order_details_subsection_title_{subsection_id}', $subsection_title );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$subsection_title` | `string` | The subsection title. |

## Since

- `1.3.0`

## Source

`inc/order-details.php`

## Examples

In `fc_pro_order_details_subsection_title_{subsection_id}`, `order_notes` replaces `{subsection_id}`.

```php
add_filter( 'fc_pro_order_details_subsection_title_order_notes',
    /**
     * Customize the Order Notes subsection title.
     *
     * @param string $subsection_title The subsection title.
     * @return string Filtered value.
     */
    function( $subsection_title ) {
        return __( 'Your Special Instructions', 'text-domain' );
    },
    10
);
```
