**Type:** Filter

Filters whether a checkout substep is complete.

The dynamic portion of the hook name, `$substep_id`, is the checkout substep ID. Known substep IDs used with this hook include `contact`, `shipping_address`, `billing_address`, `shipping_method`, `payment`, `order_notes`, `tyche_order_delivery`, and `attendee_details`. Compatibility modules may introduce further IDs.

## Signature

```php
apply_filters( 'fc_is_substep_complete_{substep_id}', $is_complete );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$is_complete` | `bool` | Whether a checkout substep is complete. |
