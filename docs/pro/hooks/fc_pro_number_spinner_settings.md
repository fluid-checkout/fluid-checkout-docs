**Type:** Filter

Filters the settings for number spinner.

## Signature

```php
apply_filters( 'fc_pro_number_spinner_settings', $settings );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$settings` | `array` | Settings. |

## Since

- `1.5.0`

## Source

`inc/cart-ajax.php`

## Examples

```php
add_filter( 'fc_pro_number_spinner_settings',
    /**
     * Customize number spinner button placement.
     *
     * @param array $settings Settings.
     * @return array Filtered value.
     */
    function( $settings ) {
        $settings['numberSpinnerOptions']['buttonPlacement'] = 'before';
        return $settings;
    },
    10
);
```
