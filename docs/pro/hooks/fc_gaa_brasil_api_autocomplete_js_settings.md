**Type:** Filter

Allow developers to change settings for the Brasil API address autocomplete integration.

Hook name matches standalone FCGAA for compatibility.

## Signature

```php
apply_filters( 'fc_gaa_brasil_api_autocomplete_js_settings', $brasil_api_settings );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$brasil_api_settings` | `array` | Brasil API JS settings. |

## Since

Not documented.

Source: `inc/brasil-api-address-autocomplete.php`

## Examples

```php
add_filter( 'fc_gaa_brasil_api_autocomplete_js_settings',
    /**
     * Modify Brasil API settings field mappings.
     *
     * @param array $settings The Brasil API settings array containing:
     * @return array Filtered value.
     */
    function( $settings ) {
        // Field mappings
        $settings['localeComponents'] = array(
            'state'        => 'state',
            'city'         => 'city',
            'address_1'    => 'street',
            'neighborhood' => 'neighborhood',
        );

        return $settings;
    },
    10
);
```
