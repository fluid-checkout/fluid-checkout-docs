**Type:** Filter

Filters the CSS classes for cart shipping calculator button.

## Signature

```php
apply_filters( 'fc_pro_cart_shipping_calculator_button_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `mixed` | CSS classes. |

## Since

Source: `templates/fc-pro/cart/cart/shipping-calculator.php`

## Examples

```php
add_filter( 'fc_pro_cart_shipping_calculator_button_classes',
    /**
     * Add theme button class to shipping calculator.
     *
     * @param mixed $classes CSS classes.
     * @return mixed Filtered value.
     */
    function( $classes ) {
        return $classes . ' button-custom-class';
    },
    10
);
```
