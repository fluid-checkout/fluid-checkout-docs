**Type:** Filter

Filters the HTML attributes for cart body custom.

## Signature

```php
apply_filters( 'fc_pro_cart_body_custom_attributes', $attributes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$attributes` | `array` | HTML attributes. Default empty array. |

## Since

- `2.1.8`

Source: `templates/compat/themes/dt-the7/fc-pro/cart/cart/header-cart.php`

## Examples

```php
add_filter( 'fc_pro_cart_body_custom_attributes',
    /**
     * Add custom data attribute to cart body element.
     *
     * @param array $attributes HTML attributes. Default empty array.
     * @return array Filtered value.
     */
    function( $attributes ) {
        $attributes['cart-custom-data'] = 'custom-data';
        return $attributes;
    },
    10
);
```
