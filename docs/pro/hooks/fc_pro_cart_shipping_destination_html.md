**Type:** Filter

Filters the HTML for cart shipping destination.

## Signature

```php
apply_filters( 'fc_pro_cart_shipping_destination_html', $html, $formatted_destination );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$html` | `string` | HTML markup. |
| `$formatted_destination` | `string` | Formatted shipping destination. |

## Since

- `1.4.0`

Source: `templates/compat/themes/Avada/fc-pro/cart/cart/shipping-methods-calculate-shipping.php`

## Examples

```php
add_filter( 'fc_pro_cart_shipping_destination_html',
    /**
     * Customize shipping destination display.
     *
     * @param string $html HTML markup.
     * @param string $formatted_destination Formatted shipping destination.
     * @return string Filtered value.
     */
    function( $html, $formatted_destination ) {
        $destination = WC()->countries->get_formatted_address( WC()->customer->get_shipping() );
        return '<div class="custom-shipping-dest"><strong>Shipping to:</strong> ' . $destination . '</div>';
    },
    10,
    2
);
```
