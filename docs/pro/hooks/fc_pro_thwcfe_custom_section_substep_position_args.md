**Type:** Filter

Filters the arguments for thwcfe custom section substep position.

## Signature

```php
apply_filters( 'fc_pro_thwcfe_custom_section_substep_position_args', $substep_position_args );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$substep_position_args` | `array` | The substep position args. |

## Since

- `3.0.0`

Source: `inc/compat/plugins/compat-plugin-woocommerce-checkout-field-editor-pro.php`

## Examples

```php
add_filter( 'fc_pro_thwcfe_custom_section_substep_position_args',
    /**
     * Customize custom section positions.
     *
     * @param array $substep_position_args The substep position args.
     * @return array Filtered value.
     */
    function( $substep_position_args ) {
        // Move 'after_billing_form' sections to payment step
        $substep_position_args['after_billing_form'] = array(
            'step_id' => 'payment',
            'priority' => 10
        );

        return $substep_position_args;
    },
    10
);
```
