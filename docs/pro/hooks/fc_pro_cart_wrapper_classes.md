**Type:** Filter

Filters the CSS classes for cart wrapper.

## Signature

```php
apply_filters( 'fc_pro_cart_wrapper_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default 'site-main'. |

## Since

- `1.3.0`

## Source

`templates/fc-pro/cart/cart/cart.php`

## Examples

```php
add_filter( 'fc_pro_cart_wrapper_classes',
    /**
     * Add custom class to cart wrapper.
     *
     * @param string $classes CSS classes. Default 'site-main'.
     * @return string Filtered value.
     */
    function( $classes ) {
        return $classes . ' custom-cart-wrapper';
    },
    10
);
```
