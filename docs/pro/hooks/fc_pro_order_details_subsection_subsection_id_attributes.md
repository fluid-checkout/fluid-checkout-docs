**Type:** Filter

**Aliases:** `fc_pro_order_details_subsection_downloads_attributes`, `fc_pro_order_details_subsection_order_notes_attributes`

Filters the HTML attributes for an order details subsection.

The dynamic portion of the hook name, `$subsection_id`, is the order details subsection ID. Possible hook names include:

  - `fc_pro_order_details_subsection_downloads_attributes`
  - `fc_pro_order_details_subsection_order_notes_attributes`

## Signature

```php
apply_filters( 'fc_pro_order_details_subsection_{subsection_id}_attributes', $additional_attributes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$additional_attributes` | `array` | HTML attributes. |

## Examples

In `fc_pro_order_details_subsection_{subsection_id}_attributes`, `custom_section` replaces `{subsection_id}`.

```php
add_filter( 'fc_pro_order_details_subsection_custom_section_attributes',
    /**
     * Add custom attributes to subsection.
     *
     * @param array $additional_attributes HTML attributes.
     * @return array Filtered value.
     */
    function( $additional_attributes ) {
        $additional_attributes['data-subsection'] = 'custom';
        return $additional_attributes;
    },
    10
);
```
