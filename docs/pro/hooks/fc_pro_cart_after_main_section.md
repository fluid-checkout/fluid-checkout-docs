**Type:** Action

Fires after the main section in the cart.

## Signature

```php
do_action( 'fc_pro_cart_after_main_section' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `2.1.8`

## Source

`templates/fc-pro/cart/cart/page-cart.php`

## Examples

```php
add_action( 'fc_pro_cart_after_main_section',
    /**
     * Add help section after cart main.
     */
    function() {
        echo '<div class="cart-help">';
        echo '<p>' . esc_html__( 'Need help? Contact our support team.', 'text-domain' ) . '</p>';
        echo '</div>';
    },
    10
);
```
