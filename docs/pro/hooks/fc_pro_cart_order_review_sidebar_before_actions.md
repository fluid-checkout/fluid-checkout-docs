**Type:** Action

Fires before the actions in the cart order review sidebar.

## Signature

```php
do_action( 'fc_pro_cart_order_review_sidebar_before_actions' );
```

## Parameters

This hook does not pass any parameters.

## Since

## Examples

```php
add_action( 'fc_pro_cart_order_review_sidebar_before_actions',
    /**
     * Add security badge before cart actions.
     */
    function() {
        echo '<div class="cart-security-badge">';

    10
```
