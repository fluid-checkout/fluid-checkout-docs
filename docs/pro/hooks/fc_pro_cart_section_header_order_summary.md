**Type:** Action

Fires when outputting the cart section header order summary.

## Signature

```php
do_action( 'fc_pro_cart_section_header_order_summary' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.3.0`

Source: `templates/fc-pro/cart/cart/review-order-section-cart.php`

## Examples

```php
add_action( 'fc_pro_cart_section_header_order_summary',
    /**
     * Add continue shopping link to order summary.
     */
    function() {
        echo '<a href="' . esc_url( wc_get_page_permalink( 'shop' ) ) . '" class="button">';
        echo esc_html__( 'Continue Shopping', 'text-domain' );
        echo '</a>';
    },
    15
);
```
