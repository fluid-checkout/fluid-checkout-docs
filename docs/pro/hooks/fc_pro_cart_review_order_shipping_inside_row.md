**Type:** Action

Fires when outputting the cart review order shipping inside row.

## Signature

```php
do_action( 'fc_pro_cart_review_order_shipping_inside_row' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.4.1`

Source: `templates/fc-pro/cart/cart/review-order-shipping-row.php`

## Examples

```php
add_action( 'fc_pro_cart_review_order_shipping_inside_row',
    /**
     * Add delivery date estimate inside shipping row.
     */
    function() {
        $estimated_date = date( 'M j', strtotime( '+5 days' ) );
        echo '<div class="estimated-delivery">';
        echo '<small>' . sprintf( esc_html__( 'Est. delivery: %s', 'text-domain' ), $estimated_date ) . '</small>';
        echo '</div>';
    },
    10
);
```
