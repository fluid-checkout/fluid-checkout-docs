**Type:** Action

Fires after the inner content of cart header widgets.

## Signature

```php
do_action( 'fc_pro_cart_header_widgets_inside_after' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.3.0`

Source: `inc/cart-widget-areas.php`

## Examples

```php
add_action( 'fc_pro_cart_header_widgets_inside_after',
    /**
     * Add help link after cart header widgets.
     */
    function() {
        echo '<a href="' . esc_url( home_url( '/help' ) ) . '" class="header-help-link">';
        echo esc_html__( 'Need Help?', 'text-domain' );
        echo '</a>';
    },
    10
);
```
