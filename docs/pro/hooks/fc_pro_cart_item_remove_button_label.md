**Type:** Filter

Filters the label for cart item remove button.

## Signature

```php
apply_filters( 'fc_pro_cart_item_remove_button_label', $label, $cart_item, $cart_item_key, $product );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$label` | `string` | Label text. |
| `$cart_item` | `array` | Cart item data. |
| `$cart_item_key` | `string` | Cart item key. |
| `$product` | `\WC_Product` | Product object. |

## Since

- `2.0.5`

Source: `inc/cart-page.php`

## Examples

```php
add_filter( 'fc_pro_cart_item_remove_button_label',
    /**
     * Customize remove button label.
     *
     * @param string $label Label text.
     * @param array $cart_item Cart item data.
     * @param string $cart_item_key Cart item key.
     * @param \WC_Product $product Product object.
     * @return string Filtered value.
     */
    function( $label, $cart_item, $cart_item_key, $product ) {
        return __( 'Delete', 'text-domain' );
    },
    10,
    4
);
```
