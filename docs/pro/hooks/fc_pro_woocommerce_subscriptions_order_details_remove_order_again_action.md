**Type:** Filter

Filters whether to remove the "Order again" action from subscription orders.

`true` removes the action. `false` keeps it.

## Signature

```php
apply_filters( 'fc_pro_woocommerce_subscriptions_order_details_remove_order_again_action', $remove );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$remove` | `bool` | Whether to remove the "Order again" action. <code>true</code> removes it, <code>false</code> keeps it. Default true. |
