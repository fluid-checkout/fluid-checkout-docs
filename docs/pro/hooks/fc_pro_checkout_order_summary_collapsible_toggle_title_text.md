**Type:** Filter

Filters the text for checkout order summary collapsible toggle title.

## Signature

```php
apply_filters( 'fc_pro_checkout_order_summary_collapsible_toggle_title_text', $text, $cart_items_count );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$text` | `string` | Text. |
| `$cart_items_count` | `int` | Number of items in the cart. |

## Since

- `4.0.0`

Source: `inc/checkout-order-summary.php`

## Examples

```php
add_filter( 'fc_pro_checkout_order_summary_collapsible_toggle_title_text',
    /**
     * Always show a custom toggle title.
     *
     * @param string $text Text.
     * @param int $cart_items_count Number of items in the cart.
     * @return string Filtered value.
     */
    function( $text, $cart_items_count ) {
        return sprintf( _n( 'Review your %d item', 'Review your %d items', $cart_items_count, 'your-text-domain' ), $cart_items_count );
    },
    10,
    2
);
```
