**Type:** Filter

Filters the order pay is same address data before.

## Signature

```php
apply_filters( 'fc_pro_order_pay_is_same_address_data_before', $value, $order );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `mixed` | Filtered value. |
| `$order` | `\WC_Order` | Order object. |

## Since

- `3.0.0`

## Source

`inc/order-pay-page.php`

## Examples

```php
add_filter( 'fc_pro_order_pay_is_same_address_data_before',
    /**
     * Force addresses to be considered different for specific payment methods.
     *
     * @param mixed $value Filtered value.
     * @param \WC_Order $order Order object.
     * @return mixed Filtered value.
     */
    function( $value, $order ) {
        // Force different for bank transfer
        if ( 'bacs' === $order->get_payment_method() ) {
            return false;
        }

        return $value;
    },
    10,
    2
);
```
