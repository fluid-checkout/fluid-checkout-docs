**Type:** Action

Fires after the fields in the woocommerce germanized preferred delivery.

## Signature

```php
do_action( 'fc_pro_woocommerce_germanized_preferred_delivery_after_fields' );
```

## Parameters

This hook does not pass any parameters.

## Examples

```php
add_action( 'fc_pro_woocommerce_germanized_preferred_delivery_after_fields',
    /**
     * Customize this hook.
     */
    function() {
        // Get value

        // Output substep state hidden field
```
