**Type:** Filter

Filters the Activate AJAX success payload.

The admin script dispatches `fc_admin_license_key_activated` with this payload after a successful request. Listeners can add keys for their own UI.

## Signature

```php
apply_filters( 'fc_admin_license_key_activate_response', $plugin_slug, $config, $arg3 );
```
