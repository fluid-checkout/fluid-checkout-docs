**Type:** Filter

Filters whether to load cart compatibility styles for a specific plugin.

The dynamic portion of the hook name, `$plugin_slug`, is the plugin directory slug (the folder name, or the file name without `.php` for single-file plugins). Anything other than `true` skips loading that compatibility module. The default is `true`.

## Signature

```php
apply_filters( 'fc_pro_enable_compat_cart_plugin_style_{plugin_slug}', $enabled );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$enabled` | `bool` | Whether to load cart compatibility styles for a specific plugin. Default true. |
