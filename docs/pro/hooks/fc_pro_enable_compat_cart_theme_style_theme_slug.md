**Type:** Filter

Filters whether to load cart compatibility styles for a specific theme.

The dynamic portion of the hook name, `$theme_slug`, is the active theme directory slug. Both the parent theme (`get_template()`) and the child theme (`get_stylesheet()`) are checked. Anything other than `true` skips loading that compatibility module. The default is `true`.

## Signature

```php
apply_filters( 'fc_pro_enable_compat_cart_theme_style_{theme_slug}', $enabled );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$enabled` | `bool` | Whether to load cart compatibility styles for a specific theme. Default true. |
