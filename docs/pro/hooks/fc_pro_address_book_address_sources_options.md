**Type:** Filter

Filter checkout address source options for the address book selector.

Option keys may include `saved`, `new`, `same_as_billing`, and `same_as_shipping`. Removing a key also removes it from the sources available to `get_selected_address_source()`.

## Signature

```php
apply_filters( 'fc_pro_address_book_address_sources_options', $options, $address_type, $address_source );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$options` | `array` | Address source options. Keys are stored values; values are labels. |
| `$address_type` | `string` | Address type (<code>shipping</code> or <code>billing</code>). |
| `$address_source` | `string` \| `null` | Currently selected address source, if any. |

## Since

Not documented.

Source: `inc/address-book.php`

## Examples

```php
add_filter( 'fc_pro_address_book_address_sources_options',
    /**
     * Change the "Enter a new address" label to something else.
     *
     * @param array $options Address source options.
     * @param string $address_type Address type ( billing / shipping ).
     * @param string $address_source Address source identifier.
     * @return array Filtered value.
     */
    function( $options, $address_type, $address_source ) {
        // Change the "Enter a new address" label
        if ( isset( $options['new'] ) ) {
            $options['new'] = __( 'Add New Address', 'your-text-domain' );
        }
        return $options;
    },
    10,
    3
);
```
