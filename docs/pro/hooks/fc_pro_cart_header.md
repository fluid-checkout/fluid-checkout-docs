**Type:** Action

Fires when outputting the cart header.

## Signature

```php
do_action( 'fc_pro_cart_header' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.3.0`

Source: `templates/compat/themes/dt-the7/fc-pro/cart/cart/header-cart.php`

## Examples

```php
add_action( 'fc_pro_cart_header',
    /**
     * Add cart header branding.
     */
    function() {
        echo '<div class="cart-header-branding">';
        echo '<p style="text-align: center;">' . esc_html__( 'Custom Information', 'text-domain' ) . '</p>';
        echo '</div>';
    },
    5
);
```
