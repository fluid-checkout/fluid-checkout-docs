**Type:** Filter

Filters extra arguments merged into the VAT number field on the edit-account form.

Merged with `wp_parse_args()` onto the billing VAT number field arguments before the field is rendered. After this filter, `required` is forced to false, so this hook cannot make the account-details field required.

## Signature

```php
apply_filters( 'fc_vat_vat_number_account_details_field_additional_args', $additional_args );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$additional_args` | `array` | WooCommerce form field arguments to merge in. Default empty array. |
