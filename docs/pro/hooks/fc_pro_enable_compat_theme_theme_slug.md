**Type:** Filter

Filters whether to load the compatibility module for a specific theme.

The dynamic portion of the hook name, `$theme_slug`, is the active theme directory slug. Both the parent theme (`get_template()`) and the child theme (`get_stylesheet()`) are checked. Anything other than `true` skips loading that compatibility module. The default is `true`.

## Signature

```php
apply_filters( 'fc_pro_enable_compat_theme_{theme_slug}', $enabled );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$enabled` | `bool` | Whether to load the compatibility module for a specific theme. Default true. |

## Since

- `1.4.1`

Source: `fluid-checkout-pro.php`

## Examples

In `fc_pro_enable_compat_theme_{theme_slug}`, `twentytwentyfive` replaces `{theme_slug}`.

```php
add_filter( 'fc_pro_enable_compat_theme_twentytwentyfive',
    /**
     * Disable Twenty Twenty-Five theme compatibility.
     *
     * @param bool $enabled Whether to load the compatibility module for a specific theme. Default true.
     * @return bool Filtered value.
     */
    function( $enabled ) {
        return false;
    },
    10
);
```
