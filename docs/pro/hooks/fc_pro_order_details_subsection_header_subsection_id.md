**Type:** Action

**Aliases:** `fc_pro_order_details_subsection_header_downloads`, `fc_pro_order_details_subsection_header_order_notes`

Fires in the header of an order details subsection.

The dynamic portion of the hook name, `$subsection_id`, is the order details subsection ID. Possible hook names include:

  - `fc_pro_order_details_subsection_header_downloads`
  - `fc_pro_order_details_subsection_header_order_notes`

## Signature

```php
do_action( 'fc_pro_order_details_subsection_header_{subsection_id}', $subsection_id );
```

| --- | --- | --- |

## Examples

In `fc_pro_order_details_subsection_header_{subsection_id}`, `order_notes` replaces `{subsection_id}`.

```php
add_action( 'fc_pro_order_details_subsection_header_order_notes',
    /**
     * Add custom information in order notes subsection header.
     *
     * @param string $subsection_id Subsection ID.
     */
    function( $subsection_id ) {
        echo '<div class="order-notes-custom-info">';
        echo esc_html__( 'Custom information', 'text-domain' );
        echo '</div>';

    10
```
