**Type:** Action

Fires after the inner content of the order review in the order pay.

## Signature

```php
do_action( 'fc_pro_order_pay_after_order_review_inside', $order );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$order` | `\WC_Order` | Order object. |

## Since

- `3.0.0`

Source: `templates/fc-pro/order-pay/order-pay/review-order-section.php`

## Examples

```php
add_action( 'fc_pro_order_pay_after_order_review_inside',
    /**
     * Add help text inside order review.
     *
     * @param \WC_Order $order Order object.
     */
    function( $order ) {
        echo '<div class="order-review-help">';
        echo '<p>' . esc_html__( 'Questions about your order? Contact our support team.', 'text-domain' ) . '</p>';
        echo '</div>';
    },
    10
);
```
