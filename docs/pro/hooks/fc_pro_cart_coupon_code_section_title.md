**Type:** Filter

Filters the title for cart coupon code section.

## Signature

```php
apply_filters( 'fc_pro_cart_coupon_code_section_title', $title );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$title` | `string` | Title text. |

## Since

- `1.3.0`

Source: `inc/cart-ajax.php`

## Examples

```php
add_filter( 'fc_pro_cart_coupon_code_section_title',
    /**
     * Customize coupon section title.
     *
     * @param string $title Title text.
     * @return string Filtered value.
     */
    function( $title ) {
        return __( 'Promo Code', 'text-domain' );
    },
    10
);
```
