**Type:** Filter

Filters the CSS classes for order received notice.

## Signature

```php
apply_filters( 'fc_pro_order_received_notice_classes', $classes, $order );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default empty. |
| `$order` | `\WC_Order` \| `false` | Order object. |

## Since

- `1.3.0`

Source: `templates/fc-pro/order-received/checkout/order-received-failed.php`

## Examples

```php
add_filter( 'fc_pro_order_received_notice_classes',
    /**
     * Add status-specific class to order received notice.
     *
     * @param string $classes CSS classes. Default empty.
     * @param \WC_Order|false $order Order object.
     * @return string Filtered value.
     */
    function( $classes, $order ) {
        $classes .= ' order-status-' . $order->get_status();
        return $classes;
    },
    10,
    2
);
```
