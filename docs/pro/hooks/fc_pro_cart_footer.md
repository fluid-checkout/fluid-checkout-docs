**Type:** Action

Fires when outputting the cart footer.

## Signature

```php
do_action( 'fc_pro_cart_footer' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.3.0`

## Source

`templates/compat/themes/enfold/fc-pro/cart/cart/footer-cart.php`

## Examples

```php
add_action( 'fc_pro_cart_footer',
    /**
     * Add cart footer content.
     */
    function() {
        // Only on cart page
        if ( ! is_cart() ) { return; }

        echo '<div class="cart-footer-content">';
        echo '<p>&copy; ' . date( 'Y' ) . ' ' . esc_html( get_bloginfo( 'name' ) ) . '</p>';
        echo '</div>';
    },
    10
);
```
