**Type:** Action

Fires after the content in the cart.

## Signature

```php
do_action( 'fc_pro_cart_after_content' );
```

## Parameters

This hook does not pass any parameters.

## Since

- `1.3.0`

## Source

`templates/fc-pro/cart/cart/cart.php`

## Examples

```php
add_action( 'fc_pro_cart_after_content',
    /**
     * Add trust badges after cart content.
     */
    function() {
        echo '<div class="cart-trust-badges">';
        echo '<p>' . esc_html__( '🔒 Secure Checkout | 📦 Free Returns', 'text-domain' ) . '</p>';
        echo '</div>';
    },
    10
);
```
