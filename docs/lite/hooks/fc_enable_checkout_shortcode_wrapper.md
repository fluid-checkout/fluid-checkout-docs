**Type:** Filter

Filters whether the checkout shortcode output is wrapped in the content container.

## Signature

```php
apply_filters( 'fc_enable_checkout_shortcode_wrapper', $enabled );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$enabled` | `bool` | Whether the feature is enabled. Default false. |

## Since

- `4.0.0`

## Source

[`inc/checkout-page-template.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/checkout-page-template.php)

## Examples

Priority here is important to be set higher than 10 because maybe_enable_checkout_shortcode_wrapper may also be setting changing the returned value to true.

```php
add_filter( 'fc_enable_checkout_shortcode_wrapper',
    /**
     * Disable checkout shortcode wrapper for custom styling.
     *
     * @param bool $enabled Whether the feature is enabled. Default false.
     * @return bool Filtered value.
     */
    function( $enabled ) {
        return false;
    },
    20
);
```
