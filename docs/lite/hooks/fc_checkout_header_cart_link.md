**Type:** Action

Fires where the checkout header cart link is rendered.

## Signature

```php
do_action( 'fc_checkout_header_cart_link' );
```

## Parameters

This hook does not pass any parameters.

## Examples

```php
add_action( 'fc_checkout_header_cart_link',
    /**
     * Add custom cart link.

    function() {

    10
```
