**Type:** Filter

Filters the label of the button that proceeds to the next checkout step.

## Signature

```php
apply_filters( 'fc_proceed_to_next_step_button_label', $button_label, $step_id, $step_args );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$button_label` | `string` | Button label. |
| `$step_id` | `string` | Checkout step ID. |
| `$step_args` | `array` | Checkout step arguments. |

## Since

- `3.2.6`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_proceed_to_next_step_button_label',
    /**
     * Customize proceed button labels.
     *
     * @param string $button_label Button label.
     * @param string $step_id Checkout step ID.
     * @param array $step_args Checkout step arguments.
     * @return string Filtered value.
     */
    function( $button_label, $step_id, $step_args ) {
        if ( 'shipping' === $step_id ) {
            return __( 'Continue to Delivery', 'your-text-domain' );
        }
        return $button_label;
    },
    10,
    3
);
```
