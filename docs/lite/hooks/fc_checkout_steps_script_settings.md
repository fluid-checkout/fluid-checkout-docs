**Type:** Filter

Filters the checkout step settings passed to the frontend script.

## Signature

```php
apply_filters( 'fc_checkout_steps_script_settings', $settings );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$settings` | `array` | Settings to output. |

## Since

- `1.6.1`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_checkout_steps_script_settings',
    /**
     * Add custom JavaScript settings for checkout steps.
     *
     * @param array $settings Settings to output.
     * @return array Filtered value.
     */
    function( $settings ) {
        $settings['customOption'] = 'customValue';
        return $settings;
    },
    10
);
```
