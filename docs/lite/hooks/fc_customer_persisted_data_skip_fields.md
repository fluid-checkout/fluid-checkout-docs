**Type:** Filter

Filters the checkout field keys that are not restored from the session.

## Signature

```php
apply_filters( 'fc_customer_persisted_data_skip_fields', $skip_field_keys, $parsed_posted_data );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip_field_keys` | `mixed` | Skip field keys. |
| `$parsed_posted_data` | `array` | Parsed posted checkout data. |

## Since

- `1.2.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_customer_persisted_data_skip_fields',
    /**
     * Skip persisting specific custom fields.
     *
     * @param mixed $skip_field_keys Skip field keys.
     * @param array $parsed_posted_data Parsed posted checkout data.
     * @return mixed Filtered value.
     */
    function( $skip_field_keys, $parsed_posted_data ) {
        $skip_field_keys[] = 'custom_temporary_field';
        return $skip_field_keys;
    },
    10,
    2
);
```
