**Type:** Filter

Filters whether the current request is the cart page or a cart fragment.

## Signature

```php
apply_filters( 'fc_is_cart_page_or_fragment', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `bool` | Value to filter. Default false. |

## Since

- `1.6.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_is_cart_page_or_fragment',
    /**
     * Mark custom page as cart page.
     *
     * @param bool $value Value to filter. Default false.
     * @return bool Filtered value.
     */
    function( $value ) {
        if ( is_page( 'custom-cart' ) ) {
            return true;
        }
        return $value;
    },
    10
);
```
