**Type:** Filter

Filters whether the checkout step markup includes the container class.

## Signature

```php
apply_filters( 'fc_add_container_class', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `bool` | CSS classes. Default true. |

## Since

- `1.6.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_add_container_class',
    /**
     * Disable checkout container class for custom styling.
     *
     * @param bool $classes CSS classes. Default true.
     * @return bool Filtered value.
     */
    function( $classes ) {
        return false;
    },
    10
);
```
