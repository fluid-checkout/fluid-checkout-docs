**Type:** Filter

Filters the CSS classes that keep an optional field visible.

## Signature

```php
apply_filters( 'fc_hide_optional_fields_skip_by_class', $skip );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip` | `array` | Whether to skip the default behavior. |

## Since

- `1.5.0`

## Examples

```php
add_filter( 'fc_hide_optional_fields_skip_by_class',
    /**
     * Add custom class to skip list.
     *
     * @param array $skip Whether to skip the default behavior.
     * @return array Filtered value.
     */
    function( $skip ) {
        $skip[] = 'custom-class';
        return $skip;
    },
    10
);
```
