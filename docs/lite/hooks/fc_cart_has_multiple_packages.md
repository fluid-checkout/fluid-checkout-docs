**Type:** Filter

Filters whether the cart is treated as having multiple shipping packages.

## Signature

```php
apply_filters( 'fc_cart_has_multiple_packages', $has_multiple_packages );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$has_multiple_packages` | `bool` | Whether the cart has multiple shipping packages. |

## Since

- `3.2.5`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_cart_has_multiple_packages',
    /**
     * Force single package display even with multiple packages.
     *
     * @param bool $has_multiple_packages Whether the cart has multiple shipping packages.
     * @return bool Filtered value.
     */
    function( $has_multiple_packages ) {
        return false; // Always treat as single package
    },
    10
);
```
