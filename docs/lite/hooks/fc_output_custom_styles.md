**Type:** Filter

Filters the custom CSS output for the checkout design.

## Signature

```php
apply_filters( 'fc_output_custom_styles', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. Default empty string. |

## Since

- `1.4.2`

## Source

[`inc/design-templates.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/design-templates.php)

## Examples

```php
add_filter( 'fc_output_custom_styles',
    /**
     * Add custom CSS to checkout page.
     *
     * @param string $value Value to filter. Default empty string.
     * @return string Filtered value.
     */
    function( $value ) {
        $value .= '
            .fc-custom-class { 
                width: 100%; 
            }
        ';
        return $value;
    },
    10
);
```
