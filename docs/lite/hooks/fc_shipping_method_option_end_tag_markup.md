**Type:** Filter

Filters the closing markup of the shipping method options list.

## Signature

```php
apply_filters( 'fc_shipping_method_option_end_tag_markup', $html );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$html` | `string` | HTML markup. Default <code>&lt;/ul&gt;</code>. |

## Since

- `1.2.0`

Source: `templates/compat/plugins/woocommerce-subscriptions/cart/cart-recurring-shipping.php`

## Examples

```php
add_filter( 'fc_shipping_method_option_end_tag_markup',
    /**
     * Add custom content after shipping methods.
     *
     * @param string $html HTML markup. Default.
     * @return string Filtered value.
     */
    function( $html ) {
        return '</ul><!-- End shipping methods -->';
    },
    10
);
```
