**Type:** Filter

Filters the toggle label of an expansible section.

The dynamic portion of the hook name, `$section_id`, refers to the expansible section ID. Possible hook names include:

- `fc_expansible_section_toggle_label_coupon_code`

## Signature

```php
apply_filters( 'fc_expansible_section_toggle_label_{section_id}', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. |

## Since

- `2.0.5`

## Examples

In `fc_expansible_section_toggle_label_{section_id}`, `coupon_code` replaces `{section_id}`.

```php
add_filter( 'fc_expansible_section_toggle_label_coupon_code',
    /**
     * Customize coupon code toggle label.
     *
     * @param string $value Value to filter.
     * @return string Filtered value.
     */
    function( $value ) {
        return __( 'Have a discount code?', 'my-theme' );
    },
    10
);
```
