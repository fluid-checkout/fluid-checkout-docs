**Type:** Filter

Filters whether checkout fragments update when the page becomes visible again.

## Signature

```php
apply_filters( 'fc_checkout_update_on_visibility_change', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. Default <code>yes</code>. |

## Since

- `2.5.0`

## Source

[`inc/enqueue.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/enqueue.php)

## Examples

```php
add_filter( 'fc_checkout_update_on_visibility_change',
    /**
     * Disable checkout update on visibility change.
     *
     * @param string $value Value to filter. Default yes.
     * @return string Filtered value.
     */
    function( $value ) {
        return 'no';
    },
    10
);
```
