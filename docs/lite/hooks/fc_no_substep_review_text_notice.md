**Type:** Filter

Filters the no substep review text notice.

## Signature

```php
apply_filters( 'fc_no_substep_review_text_notice', $text, $substep_id );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$text` | `string` | Text to display. |
| `$substep_id` | `string` | Checkout substep ID. |

## Since

- `1.5.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_no_substep_review_text_notice',
    /**
     * Customize no substep review text notice.
     *
     * @param string $text Text to display.
     * @param string $substep_id Checkout substep ID.
     * @return string Filtered value.
     */
    function( $text, $substep_id ) {
        if ( 'order_notes' === $substep_id ) {
            return __( 'No notes added.', 'my-theme' );
        }
        return __( 'Not specified.', 'my-theme' );
    },
    10,
    2
);
```
