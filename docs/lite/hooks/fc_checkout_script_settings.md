**Type:** Filter

Filters the checkout behavior settings passed to the frontend script.

## Signature

```php
apply_filters( 'fc_checkout_script_settings', $settings );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$settings` | `array` | Settings to output. |

## Since

- `3.2.2`

Source: `inc/enqueue.php`

## Examples

```php
add_filter( 'fc_checkout_script_settings',
    /**
     * Customize checkout script settings.
     *
     * @param array $settings Settings to output.
     * @return array Filtered value.
     */
    function( $settings ) {
        $settings['customCheckoutOption'] = 'value';
        return $settings;
    },
    10
);
```
