**Type:** Filter

Filters whether AJAX login is enabled at checkout.

## Signature

```php
apply_filters( 'fc_enable_checkout_ajax_login', $enabled );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$enabled` | `bool` | Whether the feature is enabled. Default true. |
