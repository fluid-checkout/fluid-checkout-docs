**Type:** Filter

Filters custom attributes added inside the checkout form wrapper.

## Signature

```php
apply_filters( 'fc_checkout_wrapper_inside_element_custom_attributes', $attributes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$attributes` | `array` | HTML attributes as an associative array. Default empty array. |

## Since

- `3.0.1`

## Source

[`templates/fc/checkout-steps/checkout/form-checkout.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/templates/fc/checkout-steps/checkout/form-checkout.php)

## Examples

Currently does not accept class attributes.

```php
add_filter( 'fc_checkout_wrapper_inside_element_custom_attributes',
    /**
     * Add custom attributes to checkout wrapper inside element.
     *
     * @param array $attributes HTML attributes as an associative array. Default empty array.
     * @return array Filtered value.
     */
    function( $attributes ) {
        $attributes['data-custom'] = 'fc-inside-custom-data';
        return $attributes;
    },
    10
);
```
