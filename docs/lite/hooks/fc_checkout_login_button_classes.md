**Type:** Filter

Filters the CSS classes of the login submit button.

## Signature

```php
apply_filters( 'fc_checkout_login_button_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default <code>woocommerce-button button</code>. |

## Since

- `4.0.5`

## Source

[`templates/fc/checkout-steps/global/form-login.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/templates/fc/checkout-steps/global/form-login.php)

## Examples

```php
add_filter( 'fc_checkout_login_button_classes',
    /**
     * Add custom classes to login button.
     *
     * @param string $classes CSS classes. Default woocommerce-button button.
     * @return string Filtered value.
     */
    function( $classes ) {
        return $classes . ' custom-login-btn';
    },
    10
);
```
