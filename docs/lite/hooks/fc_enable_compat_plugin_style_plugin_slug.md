**Type:** Filter

Filters whether to enqueue a plugin compatibility stylesheet on checkout and account screens.

The dynamic portion of the hook name, `$plugin_slug`, refers to the plugin directory slug (or the plugin file name without `.php` for single-file plugins). Return boolean `true` to enqueue the stylesheet. Any other value skips it.

## Signature

```php
apply_filters( 'fc_enable_compat_plugin_style_{plugin_slug}', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `bool` | Value to filter. Default true. |
