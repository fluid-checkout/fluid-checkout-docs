**Type:** Filter

Filters whether the phone number is added to formatted address formats.

## Signature

```php
apply_filters( 'fc_add_phone_localisation_formats', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. Default <code>yes</code>. |

## Since

- `1.5.0`

## Source

## Examples

```php
add_filter( 'fc_add_phone_localisation_formats',
    /**
     * Disable phone number in formatted addresses.
     *
     * @param string $value Value to filter. Default yes.
     * @return string Filtered value.
     */
    function( $value ) {
        return 'no';
    },
    150
);
```
