**Type:** Filter

Filters the persisted checkout field keys cleared after the order is processed.

## Signature

```php
apply_filters( 'fc_customer_persisted_data_clear_fields_order_processed', $clear_field_keys );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$clear_field_keys` | `mixed` | Clear field keys. |

## Since

- `1.4.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_customer_persisted_data_clear_fields_order_processed',
    /**
     * Clear custom fields after order is placed.
     *
     * @param mixed $clear_field_keys Clear field keys.
     * @return mixed Filtered value.
     */
    function( $clear_field_keys ) {
        $clear_field_keys[] = 'custom_field';

        return $clear_field_keys;
    },
    10
);
```
