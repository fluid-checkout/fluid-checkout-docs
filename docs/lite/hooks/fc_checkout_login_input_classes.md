**Type:** Filter

Filters extra CSS classes for the checkout login inputs.

## Signature

```php
apply_filters( 'fc_checkout_login_input_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default empty string. |
