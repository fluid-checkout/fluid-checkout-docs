**Type:** Action

Fires inside each order summary cart item, where the product details are rendered.

## Signature

```php
do_action( 'fc_order_summary_cart_item_details', $cart_item, $cart_item_key, $_product );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$cart_item` | `array` | Cart item data. |
| `$cart_item_key` | `string` | Cart item key. |
| `$_product` | `\WC_Product` | Product object. |

- `2.1.0`

[`templates/fc/checkout-steps/checkout/review-order.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/templates/fc/checkout-steps/checkout/review-order.php)

## Examples

```php
add_action( 'fc_order_summary_cart_item_details',
    /**
     * Add product SKU to cart item details.
     *
     * @param array $cart_item Cart item data.
     * @param string $cart_item_key Cart item key.
     * @param \WC_Product $_product Product object.
     */
    function( $cart_item, $cart_item_key, $_product ) {
        if ( $_product->get_sku() ) {
            echo '<div class="cart-item__element cart-item__sku">SKU: ' . esc_html( $_product->get_sku() ) . '</div>';
        }
    },
    10,
    3
);
```
