**Type:** Filter

Filters the CSS class for the login form wrapper.

## Signature

```php
apply_filters( 'fc_login_form_wrapper_class', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default empty string. |

## Since

- `4.1.0`

## Source

[`templates/fc/checkout-steps/checkout/form-contact-login-modal.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/templates/fc/checkout-steps/checkout/form-contact-login-modal.php)

## Examples

```php
add_filter( 'fc_login_form_wrapper_class',
    /**
     * Add custom classes to login form wrapper.
     *
     * @param string $classes CSS classes. Default empty string.
     * @return string Filtered value.
     */
    function( $classes ) {
        return 'custom-login-wrapper';
    },
    10
);
```
