**Type:** Filter

Filters the CSS classes of the apply-coupon button.

## Signature

```php
apply_filters( 'fc_coupon_code_apply_button_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default <code>button</code>. |

## Since

- `1.2.0`

## Examples

```php
add_filter( 'fc_coupon_code_apply_button_classes',
    /**
     * Add custom classes to coupon code apply button.
     *
     * @param string $classes CSS classes. Default button.
     * @return string Filtered value.
     */
    function( $classes ) {
        return $classes . ' custom-button-class';
    },
    10
);
```
