**Type:** Filter

Filters the billing field keys copied from the shipping address.

## Signature

```php
apply_filters( 'fc_billing_same_as_shipping_field_keys', $billing_copy_shipping_field_keys );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$billing_copy_shipping_field_keys` | `mixed` | Billing copy shipping field keys. |

## Since

- `1.2.9`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_billing_same_as_shipping_field_keys',
    /**
     * Add custom field to shipping to billing copy.
     *
     * @param mixed $billing_copy_shipping_field_keys Billing copy shipping field keys.
     * @return mixed Filtered value.
     */
    function( $billing_copy_shipping_field_keys ) {
        $billing_copy_shipping_field_keys[] = 'billing_company';
        return $billing_copy_shipping_field_keys;
    },
    10
);
```
