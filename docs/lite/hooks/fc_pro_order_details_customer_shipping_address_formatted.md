**Type:** Filter

Filters the formatted shipping address shown in order details.

## Signature

```php
apply_filters( 'fc_pro_order_details_customer_shipping_address_formatted', $value, $order );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. |
| `$order` | `\WC_Order` | Order object. |

## Since

- `3.2.0`

## Examples

```php
add_filter( 'fc_pro_order_details_customer_shipping_address_formatted',
    /**
     * Wrap shipping address in a custom HTML wrapper.
     *
     * @param string $value Value to filter.
     * @param \WC_Order $order Order object.
     * @return string Filtered value.
     */
    function( $value, $order ) {
        return '<div class="custom-shipping-wrapper">' . $value . '</div>';
    },
    10,
    2
);
```
