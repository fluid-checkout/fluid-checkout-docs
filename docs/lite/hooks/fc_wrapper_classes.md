**Type:** Filter

Filters the CSS classes for the wrapper.

## Signature

```php
apply_filters( 'fc_wrapper_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default empty string. |

## Since

- `1.2.0`

## Source

[`templates/fc/checkout-steps/checkout/form-checkout.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/templates/fc/checkout-steps/checkout/form-checkout.php)

## Examples

```php
add_filter( 'fc_wrapper_classes',
    /**
     * Add custom wrapper classes.
     *
     * @param string $classes CSS classes. Default empty string.
     * @return string Filtered value.
     */
    function( $classes ) {
        $classes .= ' custom-checkout-wrapper';
        return $classes;
    },
    10
);
```
