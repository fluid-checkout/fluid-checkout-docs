**Type:** Filter

Filters the label of the "same as billing address" option.

## Signature

```php
apply_filters( 'fc_shipping_same_as_billing_option_label', $label );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$label` | `string` | Label text. |

## Since

- `3.1.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_shipping_same_as_billing_option_label',
    /**
     * Customize shipping same as billing option label.
     *
     * @param string $label Label text.
     * @return string Filtered value.
     */
    function( $label ) {
        return __( 'Use billing address for shipping', 'my-theme' );
    },
    10
);
```
