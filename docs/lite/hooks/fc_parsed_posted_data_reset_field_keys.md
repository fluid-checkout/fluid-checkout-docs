**Type:** Filter

Filters the parsed posted data reset field keys.

## Signature

```php
apply_filters( 'fc_parsed_posted_data_reset_field_keys', $value, $posted_data );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `array` | Value to filter. |
| `$posted_data` | `array` | Parsed posted checkout data. |

## Since

- `3.0.3`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_parsed_posted_data_reset_field_keys',
    /**
     * Add custom checkbox fields to reset list.
     *
     * @param array $value Value to filter.
     * @param array $posted_data Parsed posted checkout data.
     * @return array Filtered value.
     */
    function( $value, $posted_data ) {
        $value[] = 'custom_field';
        return $value;
    },
    10,
    2
);
```
