**Type:** Filter

Filters the description of the billing email field.

## Signature

```php
apply_filters( 'fc_checkout_email_field_description', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. |

## Examples

```php
add_filter( 'fc_checkout_email_field_description',
    /**
     * Customize email field description.
     *
     * @param string $value Value to filter.
     * @return string Filtered value.
     */
    function( $value ) {
        return __( 'We will send your order confirmation to this email address.', 'your-text-domain' );
    },
    10
);
```
