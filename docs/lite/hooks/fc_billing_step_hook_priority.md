**Type:** Filter

Filters the priority of the billing checkout step.

## Signature

```php
apply_filters( 'fc_billing_step_hook_priority', $step_priority );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$step_priority` | `mixed` | Step priority. |

## Since

- `3.1.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_billing_step_hook_priority',
    /**
     * Change billing step hooks priority.
     *
     * @param mixed $step_priority Step priority.
     * @return mixed Filtered value.
     */
    function( $step_priority ) {
        // Force billing step before shipping
        return 15;
    },
    10
);
```
