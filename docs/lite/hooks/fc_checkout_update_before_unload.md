**Type:** Filter

Filters whether checkout fragments update before the page unloads.

## Signature

```php
apply_filters( 'fc_checkout_update_before_unload', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `string` | Value to filter. Default <code>yes</code>. |

## Since

- `1.5.2`

## Source

[`inc/enqueue.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/enqueue.php)

## Examples

```php
add_filter( 'fc_checkout_update_before_unload',
    /**
     * Disable checkout update before page unload.
     *
     * @param string $value Value to filter. Default yes.
     * @return string Filtered value.
     */
    function( $value ) {
        return 'no';
    },
    10
);
```
