**Type:** Filter

Filters the CSS variables output for Fluid Checkout design templates.

## Signature

```php
apply_filters( 'fc_css_variables', $value, $context );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `array` | Value to filter. |
| `$context` | `string` | Context in which the hook runs. Default <code>checkout</code>. |

## Since

- `3.0.0`

## Source

[`inc/design-templates.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/design-templates.php)

## Examples

```php
add_filter( 'fc_css_variables',
    /**
     * Add custom CSS variables.
     *
     * @param array $value Value to filter.
     * @param string $context Context in which the hook runs. Default checkout.
     * @return array Filtered value.
     */
    function( $value, $context ) {
        if ( 'frontend' === $context ) {
            $new_css_variables = array(
                ':root' => array(
                // Change field height
                '--fluidcheckout--field--height' => '50px',
                )
            );

            return FluidCheckout_DesignTemplates::instance()->merge_css_variables( $value, $new_css_variables );
        }
        return $value;
    },
    100,
    2
);
```
