**Type:** Filter

Filters the CSS class for the login form.

## Signature

```php
apply_filters( 'fc_login_form_class', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default empty string. |

## Since

- `4.1.0`

## Source

[`templates/fc/checkout-steps/checkout/form-contact-login-modal.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/templates/fc/checkout-steps/checkout/form-contact-login-modal.php)

## Examples

```php
add_filter( 'fc_login_form_class',
    /**
     * Add custom classes to login form.
     *
     * @param string $classes CSS classes. Default empty string.
     * @return string Filtered value.
     */
    function( $classes ) {
        return 'custom-login-form';
    },
    10
);
```
