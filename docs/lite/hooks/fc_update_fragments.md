**Type:** Filter

Filters the HTML fragments returned by the fragment-refresh request.

## Signature

```php
apply_filters( 'fc_update_fragments', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `array` | Value to filter. Default empty array. |

## Since

- `3.0.4`

Source: `inc/fragments-refresh.php`

## Examples

```php
add_filter( 'fc_update_fragments',
    /**
     * Customize this hook.
     *
     * @param array $value Value to filter. Default empty array.
     * @return array Filtered value.
     */
    function( $value ) {
        $html = $this->get_vat_number_field_html();
        $value['.fc-vat-number-field'] = $html;
        return $value;
    },
    10
);
```
