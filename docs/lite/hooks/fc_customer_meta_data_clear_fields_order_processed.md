**Type:** Filter

Filters the customer meta keys cleared after the order is processed.

## Signature

```php
apply_filters( 'fc_customer_meta_data_clear_fields_order_processed', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `array` | Value to filter. Default empty array. |

## Since

- `2.0.3`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_customer_meta_data_clear_fields_order_processed',
    /**
     * Clear custom customer meta after order.
     *
     * @param array $value Value to filter. Default empty array.
     * @return array Filtered value.
     */
    function( $value ) {
        $value[] = '_custom_temporary_preference';
        return $value;
    },
    10
);
```
