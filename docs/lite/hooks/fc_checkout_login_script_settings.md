**Type:** Filter

Filters the login settings passed to the frontend script.

## Signature

```php
apply_filters( 'fc_checkout_login_script_settings', $settings );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$settings` | `array` | Settings to output. |

## Since

- `4.0.4`

Source: `inc/checkout-login.php`

## Examples

```php
add_filter( 'fc_checkout_login_script_settings',
    /**
     * Add custom JavaScript settings for checkout login.
     *
     * @param array $settings Settings to output.
     * @return array Filtered value.
     */
    function( $settings ) {
        $settings['customOption'] = 'customValue';

        return $settings;
    },
    10
);
```
