**Type:** Filter

Filters the CSS selectors of fields that trigger a checkout update.

## Signature

```php
apply_filters( 'fc_checkout_update_fields_selectors', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `array` | Value to filter. |

## Since

- `1.5.0`

## Source

[`inc/enqueue.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/enqueue.php)

## Examples

```php
add_filter( 'fc_checkout_update_fields_selectors',
    /**
     * Add custom field selectors for checkout updates.
     *
     * @param array $value Value to filter.
     * @return array Filtered value.
     */
    function( $value ) {
        $value[] = '.custom-field input';
        return $value;
    },
    10
);
```
