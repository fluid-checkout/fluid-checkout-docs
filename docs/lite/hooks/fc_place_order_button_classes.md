**Type:** Filter

Filters the CSS classes for the place order button.

## Signature

```php
apply_filters( 'fc_place_order_button_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default <code>button alt</code>. |

## Since

- `1.2.5`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_place_order_button_classes',
    /**
     * Add custom classes to place order button.
     *
     * @param string $classes CSS classes. Default button alt.
     * @return string Filtered value.
     */
    function( $classes ) {
        return $classes . ' custom-place-order-button';
    },
    10
);
```
