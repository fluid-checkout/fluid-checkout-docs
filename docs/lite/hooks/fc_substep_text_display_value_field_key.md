**Type:** Filter

Filters the substep review display value for one checkout field.

The dynamic portion of the hook name, `$field_key`, refers to the checkout field key, for example `billing_email` or `shipping_city`. This runs after the field-type hook.

## Signature

```php
apply_filters( 'fc_substep_text_display_value_{field_key}', $field_display_value, $field_value, $field_key, $field_args );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$field_display_value` | `string` | Value prepared for display in the substep review text. |
| `$field_value` | `mixed` | Submitted field value. |
| `$field_key` | `string` | Checkout field key. |
| `$field_args` | `array` | Checkout field arguments. |
