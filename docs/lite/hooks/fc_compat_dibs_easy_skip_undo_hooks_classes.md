**Type:** Filter

Filters the classes whose checkout hooks are not restored when leaving Nets Easy.

## Signature

```php
apply_filters( 'fc_compat_dibs_easy_skip_undo_hooks_classes', $skip );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip` | `array` | Whether to skip the default behavior. Default empty array. |

## Since

- `3.1.5`

## Source

[`inc/compat/plugins/compat-plugin-dibs-easy-for-woocommerce.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/compat/plugins/compat-plugin-dibs-easy-for-woocommerce.php)

## Examples

```php
add_filter( 'fc_compat_dibs_easy_skip_undo_hooks_classes',
    /**
     * Add custom feature classes to skip when undoing DIBS Easy hooks.
     *
     * @param array $skip Whether to skip the default behavior. Default empty array.
     * @return array Filtered value.
     */
    function( $skip ) {
        $skip[] = 'FluidCheckout_Feature';

        return $skip;
    },
    10
);
```
