**Type:** Action

Fires where the place-order section is rendered.

## Signature

```php
do_action( 'fc_place_order', $step_id, $is_sidebar );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$step_id` | `string` | Checkout step ID. |
| `$is_sidebar` | `bool` | Is sidebar. |

## Since

- `2.2.0`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/checkout-steps.php)

## Examples

```php
add_action( 'fc_place_order',
    /**
     * Add place order content.
     *
     * @param string $step_id Checkout step ID.
     * @param bool $is_sidebar Is sidebar.
     */
    function( $step_id, $is_sidebar ) {
        $location_class = $is_sidebar ? 'place-order-sidebar' : 'place-order-main';
        echo '<div class="place-order-info ' . esc_attr( $location_class ) . '">Review and place your order!</div>';
    },
    10,
    2
);
```
