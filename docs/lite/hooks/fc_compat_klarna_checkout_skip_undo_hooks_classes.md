**Type:** Filter

Filters the classes whose checkout hooks are not restored when leaving Klarna Checkout or Svea Checkout.

## Signature

```php
apply_filters( 'fc_compat_klarna_checkout_skip_undo_hooks_classes', $skip );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip` | `array` | Whether to skip the default behavior. Default empty array. |

## Since

- `3.0.4`

Source: `inc/compat/plugins/compat-plugin-klarna-checkout-for-woocommerce.php`

## Examples

```php
add_filter( 'fc_compat_klarna_checkout_skip_undo_hooks_classes',
    /**
     * Add custom feature classes to skip when undoing Klarna Checkout hooks.
     *
     * @param array $skip Whether to skip the default behavior. Default empty array.
     * @return array Filtered value.
     */
    function( $skip ) {
        $skip[] = 'FluidCheckout_Feature';
        return $skip;
    },
    10
);
```
