**Type:** Filter

Filters the CSS classes for the next step button.

## Signature

```php
apply_filters( 'fc_next_step_button_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `array` | CSS classes. |

## Since

- `1.4.1`

## Source

[`inc/checkout-steps.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/checkout-steps.php)

## Examples

```php
add_filter( 'fc_next_step_button_classes',
    /**
     * Add custom classes to next step button.
     *
     * @param array $classes CSS classes.
     * @return array Filtered value.
     */
    function( $classes ) {
        $classes[] = 'custom-button';
        return $classes;
    },
    10
);
```
