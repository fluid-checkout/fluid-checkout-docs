**Type:** Filter

Filters the billing field keys that are not copied from the shipping address.

## Signature

```php
apply_filters( 'fc_billing_same_as_shipping_skip_fields', $skip );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip` | `array` | Whether to skip the default behavior. Default empty array. |

## Since

- `1.2.0`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_billing_same_as_shipping_skip_fields',
    /**
     * Skip phone field when copying shipping to billing.
     *
     * @param array $skip Whether to skip the default behavior. Default empty array.
     * @return array Filtered value.
     */
    function( $skip ) {
        $skip[] = 'billing_phone';
        return $skip;
    },
    10
);
```
