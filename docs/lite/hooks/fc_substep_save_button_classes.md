**Type:** Filter

Filters the CSS classes of the substep save button.

## Signature

```php
apply_filters( 'fc_substep_save_button_classes', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default <code>button</code>. |

## Since

- `1.2.0`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_substep_save_button_classes',
    /**
     * Add custom classes to substep save button.
     *
     * @param string $classes CSS classes. Default button.
     * @return string Filtered value.
     */
    function( $classes ) {
        return $classes . ' custom-save-button';
    },
    10
);
```
