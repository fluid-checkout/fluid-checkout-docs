**Type:** Filter

Filters the locale used for each language variant when loading translations.

## Signature

```php
apply_filters( 'fc_locale_language_variant', $value );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$value` | `array` | Value to filter. |

## Since

- `2.3.2`

## Source

[`fluid-checkout.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/fluid-checkout.php)

## Examples

```php
add_filter( 'fc_locale_language_variant',
    /**
     * Customize locale language variant mappings.
     *
     * @param array $value Value to filter.
     * @return array Filtered value.
     */
    function( $value ) {
        // Modify existing mappings
        $value['pt_PT'] = 'pt_BR'; // Force using Brazilian Portuguese for Portugal

        return $value;
    },
    10
);
```
