**Type:** Filter

Filters the title of the checkout login modal.

## Signature

```php
apply_filters( 'fc_checkout_login_modal_title', $title );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$title` | `string` | Title text. |

## Since

- `2.0.5`

Source: `templates/fc/checkout-steps/checkout/form-contact-login-modal.php`

## Examples

```php
add_filter( 'fc_checkout_login_modal_title',
    /**
     * Customize login modal title.
     *
     * @param string $title Title text.
     * @return string Filtered value.
     */
    function( $title ) {
        return __( 'Sign In', 'my-theme' );
    },
    10
);
```
