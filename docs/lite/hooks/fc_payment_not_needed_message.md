**Type:** Filter

Filters the message shown when the order total does not require payment.

## Signature

```php
apply_filters( 'fc_payment_not_needed_message', $text );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$text` | `string` | Text to display. |

## Since

- `1.2.0`

## Source

[`templates/fc/checkout-steps/checkout/payment.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/templates/fc/checkout-steps/checkout/payment.php)

## Examples

```php
add_filter( 'fc_payment_not_needed_message',
    /**
     * Customize payment not needed message.
     *
     * @param string $text Text to display.
     * @return string Filtered value.
     */
    function( $text ) {
        return __( 'Your order is free! No payment required.', 'my-theme' );
    },
    10
);
```
