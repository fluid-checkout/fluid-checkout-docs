**Type:** Filter

Filters extra CSS classes for the checkout content wrapper.

## Signature

```php
apply_filters( 'fc_content_section_class', $classes );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$classes` | `string` | CSS classes. Default empty string. |

## Since

- `1.2.0`

## Source

[`inc/checkout-page-template.php`](https://github.com/fluid-checkout/fluid-checkout/blob/bd94362e871bc8abd7ada3ee6cb483762a9eca50/inc/checkout-page-template.php)

## Examples

```php
add_filter( 'fc_content_section_class',
    /**
     * Add custom classes to content section.
     *
     * @param string $classes CSS classes. Default empty string.
     * @return string Filtered value.
     */
    function( $classes ) {
        $classes .= ' custom-content-wrapper';
        return $classes;
    },
    10
);
```
