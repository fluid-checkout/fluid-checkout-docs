**Type:** Filter

Filters the notice shown when an account will be created at checkout.

## Signature

```php
apply_filters( 'fc_checkout_account_creation_notice_message', $text );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$text` | `string` | Text to display. |

## Since

- `4.1.0`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_checkout_account_creation_notice_message',
    /**
     * Customize account creation notice message.
     *
     * @param string $text Text to display.
     * @return string Filtered value.
     */
    function( $text ) {
        return __( 'Create an account to track your orders and save time on future purchases.', 'your-text-domain' );
    },
    10
);
```
