**Type:** Filter

Filters the field keys that are not hidden when optional fields are collapsed.

## Signature

```php
apply_filters( 'fc_hide_optional_fields_skip_list', $skip_list );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip_list` | `string[]` | Field keys to skip. |

## Since

- `1.2.0`

## Source

[`inc/checkout-hide-optional-fields.php`](https://github.com/fluid-checkout/fluid-checkout/blob/release/next-FEATURE/inc/checkout-hide-optional-fields.php)

## Examples

```php
add_filter( 'fc_hide_optional_fields_skip_list',
    /**
     * Skip hiding specific optional fields.
     *
     * @param string[] $skip_list Field keys to skip.
     * @return string[] Filtered value.
     */
    function( $skip_list ) {
        $skip_list[] = 'billing_company';
        $skip_list[] = 'shipping_company';
        return $skip_list;
    },
    10
);
```
