**Type:** Filter

**Aliases:** `fc_integrations_settings`

Filters the settings for one Fluid Checkout admin section.

The dynamic portion of the hook name, `$current_section`, refers to the settings section slug. At this call the section is fixed by the surrounding condition. Possible hook names include:

- `fc_integrations_settings`

## Signature

```php
apply_filters( 'fc_{current_section}_settings', $settings_new, $current_section );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$settings_new` | `array` | Settings for the current section. |
| `$current_section` | `string` | Current settings section slug. An empty string is the dashboard section. |
