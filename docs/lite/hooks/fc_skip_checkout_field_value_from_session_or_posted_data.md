**Type:** Filter

Filters the skip checkout field value from session or posted data.

## Signature

```php
apply_filters( 'fc_skip_checkout_field_value_from_session_or_posted_data', $skip, $input );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$skip` | `bool` | Whether to skip the default behavior. Default false. |
| `$input` | `mixed` | Input. |

## Since

- `4.0.2`

Source: `inc/checkout-steps.php`

## Examples

```php
add_filter( 'fc_skip_checkout_field_value_from_session_or_posted_data',
    /**
     * Skip getting field values from session for specific fields.
     *
     * @param bool $skip Whether to skip the default behavior. Default false.
     * @param mixed $input Input.
     * @return bool Filtered value.
     */
    function( $skip, $input ) {
        if ( 'billing_first_name' === $input ) {
            return true; // Skip getting phone value from session
        }
        return $skip;
    },
    10,
    2
);
```
