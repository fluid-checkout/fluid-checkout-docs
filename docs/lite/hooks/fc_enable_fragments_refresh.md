**Type:** Filter

Filters whether the checkout fragment-refresh feature is enabled.

## Signature

```php
apply_filters( 'fc_enable_fragments_refresh', $enabled );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$enabled` | `bool` | Whether the feature is enabled. Default false. |

## Since
