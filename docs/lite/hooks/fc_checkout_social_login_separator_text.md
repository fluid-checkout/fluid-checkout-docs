**Type:** Filter

Filters the separator text above the social login buttons.

## Signature

```php
apply_filters( 'fc_checkout_social_login_separator_text', $text );
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `$text` | `string` | Text to display. |

## Since

- `4.1.6`

Source: `templates/fc/checkout-steps/checkout/form-contact-login.php`

## Examples

```php
add_filter( 'fc_checkout_social_login_separator_text',
    /**
     * Customize social login separator text.
     *
     * @param string $text Text to display.
     * @return string Filtered value.
     */
    function( $text ) {
        // This will be used regardless of guest checkout setting
        return __( 'Or continue with Social Login', 'your-text-domain' );
    },
    10
);
```
