# REST API

## Using the API

Fluid Checkout Lite defines the shared `fluid-checkout/v1` REST namespace and the core wire error codes (`fc_api_*`) used by Lite, PRO, and Fluid Checkout add-ons.

Integrator-facing routes currently ship with Fluid Checkout PRO and its features. Use this Lite section for the shared error catalog and response conventions.

Namespace: `fluid-checkout/v1`. Base URL pattern: `{'{'}site{'}'}/wp-json/fluid-checkout/v1`.

## Permissions

Requests require a logged-in WordPress user. Omit user_id to use the current user's data, or pass user_id to target another account when the caller can edit that user (edit_user capability). Unauthenticated requests return fc_api_forbidden. An invalid user_id returns fc_api_user_not_found.

## Response shape

- HTTP 200 with {'{'} "data": {'{'} ... {'}'} {'}'} when the handler returns a payload.
- HTTP 200 with {'{'} "success": true {'}'} when there is no payload (for example DELETE).
- Failures return WordPress REST error JSON from WP_Error (code, message, data.status). Wire codes use the fc_api_* prefix.
