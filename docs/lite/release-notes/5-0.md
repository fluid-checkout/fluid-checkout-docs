# Fluid Checkout Lite 5.0 release notes

Fluid Checkout Lite 5.0 is now available. We encourage you to update your site as soon as possible to take advantage of the latest features, improvements, and fixes.

## 🎉 New – Settings with guided setup and live preview

Configuring Fluid Checkout used to mean hunting through settings without a clear starting path, and guessing the changes to checkout while you changed options.

Lite 5.0 ships new settings pages, with a guided setup and a live preview of the checkout pages. The guided setup is optional: it starts automatically on new installation, and you can skip it entirely. You can also find it in WP Admin > Fluid Checkout > Dashboard, in the Getting started section. Change settings at WP Admin > Fluid Checkout > Settings.

Settings locked by a compatible plugin or theme now show as disabled, with a note explaining why. The Fluid Checkout plugin icon shows on admin notices.

## 🎉 New – Boxed design template in Lite

The Boxed design template was a PRO-only look. Lite stores that wanted that layout had to upgrade or stick with Classic.

The Boxed design template is now available in Lite and is the default on new installs. Existing sites that update keep their current design template, so Classic stays in place unless you change it.

## New – Optional usage tracking

Improving compatibility and support is harder without knowing which themes, plugins and settings stores actually use. We do not and will not collect customer data from your shop.

Optional usage tracking helps improve compatibility and support. It is off by default. You can preview what would be sent, choose which groups of data to share, and turn it off at any time. When enabled, it only sends non-sensitive site information (environment, optional plugin settings, optional store totals with no customer or order details).

Agencies and developers can turn usage tracking off and hide it for a site by adding `FC_DISABLE_TELEMETRY` set to true in that site's `wp-config.php`. It has to be added on each site. While the constant is set, nothing is sent, the usage tracking settings stay hidden in the admin, and the saved choice is kept.

## ⬆️ Upgrading to 5.0

1. **Back up your site**

   As with any update, back up your site first. If you can, try the update on a staging site first.

2. **Update Fluid Checkout Lite to 5.0.0**

   Lite 5.0 comes as a normal update from your site's dashboard. Your settings and data are kept.

3. **Check your checkout**

   Test your checkout by placing a test order, and adjust the settings if needed.

:::info[Worth checking after the update]

The shipping method section now shows before the shipping address by default. The option to turn off the coupon code section and the option to prevent automatic selection of the first shipping method were removed.

:::

## Other enhancements and fixes

New:

- Support for the Split design template with the 1 column layout (PRO feature).
- Compatibility with theme Purple.
- Filter `fc_local_pickup_shipping_zone_fields_options` for the local pickup shipping zone fields setting (PRO feature).
- Filter `fc_available_shipping_methods` to change the shipping methods shown for a package.
- Filter `fc_prevent_shipping_method_autoselect`. Return `true` to prevent automatic selection of the first shipping method.

Improved:

- The shipping method section now shows before the shipping address by default.
- Layout of the WooCommerce address autocomplete suggestions and search icon on checkout and on the account edit address form.
- Updated the replaced files for WooCommerce `address-i18n.js` and for EU/UK VAT for WooCommerce.
- Updated the replaced checkout templates `form-shipping.php` and `review-order.php` for WooCommerce 11.2.0.
- Filter `fc_shipping_method_display_package_destination_substep_text_lines` also receives the shipping method and the package index.
- Upgraded the Sass build tooling.

Fixed:

- Checkout step names partly visible inside the progress bar with some themes.
- Shipping step and substep visibility when the cart starts or stops needing shipping during checkout AJAX updates.
- Progress bar not showing the right step when a hidden, incomplete step becomes visible again.
- Proceed button showing instead of the edit and save buttons for an incomplete step the customer already passed.
- 'Same as billing address' behavior on the cart shipping calculator.
- JavaScript error in collapsible blocks, for example on the view order account page.
- JavaScript error when focusing a shipping method that is no longer available after a checkout update.
- Settings page header missing when other plugins' admin notices are removed on Fluid Checkout settings screens.
- PHP deprecation notice across the plugin.
- Compatibility with plugin Brevo for WooCommerce (formerly Sendinblue). No more duplicate newsletter checkbox when it is moved to the contact step.
- Compatibility with plugin Colissimo. Dependent international phone settings are hidden when that feature is off.
- Compatibility with plugin Hungarian Pickup Points & Shipping Labels for WooCommerce. No more required shipping address errors with its pickup point method, and the map lists points for the shipping country.
- Compatibility with plugin Wawp (Automation Web Platform). The phone country code is no longer applied twice after a reload, and the country dropdown works on checkout.
- Compatibility with plugin WooCommerce Subscriptions. Recurring shipping methods no longer hidden when the only package index is 0.
- Compatibility with plugin Astra Pro. Modern input animation works when country or state fields update during checkout.
- Compatibility with plugin Svea Checkout for WooCommerce. No more endless checkout reloads, style issues or missing shipping options with versions 3.0.0+, and fields are no longer cleared when switching payment methods.

Changes for developers:

- Fixed: Plugin deactivation only syncs non-Fluid Checkout settings from the active profile to `wp_options`. Managed `fc_*` values stay in the profile.
- Deprecated: Filter `fc_next_step_button_label` now shows a notice, use `fc_proceed_to_next_step_button_label`.
- Deprecated: Filter `fc_shipping_methods_disable_auto_select`, use `fc_prevent_shipping_method_autoselect`. The new filter has inverted logic.
- Deprecated: Filter `fc_skip_add_pickup_point_info_as_review_text_lines`, use `fc_add_pickup_point_info_as_review_text_lines`.
- Removed: Option to turn off the integrated coupon code section. It is always on when WooCommerce coupons are available.
- Removed: Option `fc_local_pickup_display_clear_shipping_methods_button`, not needed with the new Local Pickup feature.
- Removed: Option to prevent automatic selection of the first shipping method. Use the filter `fc_prevent_shipping_method_autoselect` instead.
