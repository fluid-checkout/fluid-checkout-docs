# Changelog format and semantic version numbers

The changelog format is based on the WordPress plugin readme file standard, and this project adheres to [Semantic Versioning](https://semver.org/).

Given version number pattern MAJOR.MINOR.PATCH, increments are made to:

- MAJOR version when incompatible API changes are introduced, features are removed, or there are breaking changes introduced;
- MINOR version when new functionality is added in a backwards compatible manner; and
- PATCH version when backwards compatible bug and security fixes are made, compatibility with other plugins and themes are added, new language translations are added.

Additional labels for beta builds are available as extensions to the MAJOR.MINOR.PATCH format (i.e. 1.5.0-beta-1).
