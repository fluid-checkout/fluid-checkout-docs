# Archived EU-VAT Assistant changelog

This directory is not a docs route. Nothing here is published on the site.

`readme.txt` is the former EU-VAT Assistant plugin readme. Its `== Changelog ==` section is the release history from when EU-VAT Assistant was a separate plugin (26 versions, 0.1.0 through 2.1.2). `changelog.md` is the last page generated from that readme. It is kept so removing the `/eu-vat/` docs instance does not delete the history.

Fluid Checkout PRO's changelog is unchanged. This history is not appended to `/pro/changelog/`.
